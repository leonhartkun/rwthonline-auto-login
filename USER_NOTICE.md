# User Notice — RWTHonline Auto Login

Last updated: 26 July 2026

RWTHonline Auto Login is an independent, open-source browser extension created to reduce repeated manual sign-in steps on supported RWTH Aachen websites.

## What the extension does

After one-time configuration, the extension can detect supported RWTH sign-in pages, retrieve the credentials held in the local operating-system credential vault, and fill the username, password, and current time-based one-time code needed for the sign-in flow.

The extension works only on RWTH Aachen domains needed for this purpose. It does not inspect, inject into, or operate on unrelated websites.

## Your responsibility

You must use an RWTH account and Token that belong to you and comply with the terms and security requirements that apply to your RWTH account. Keep your device account protected. If you no longer want to use the extension, remove the saved vault entries through macOS Keychain or Windows Credential Manager.
